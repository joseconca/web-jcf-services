# web-jcf-services

Web estática de presentación de JC Services. Todo el sitio está en `index.html`, incluidas las imágenes optimizadas de la tarjeta y los estilos. No necesita dependencias, servidor, JavaScript, fuentes externas ni compilación.

## Vista previa

Abre `index.html` en cualquier navegador. Los enlaces de teléfono y correo requieren aplicaciones compatibles en el dispositivo. WhatsApp abre una conversación con el número +34 640 66 19 49 y un mensaje de consulta predefinido, mediante un enlace wa.me (sin widgets ni scripts externos).

## Publicación de una maqueta en GitHub Pages

1. Crea un repositorio llamado `web-jcf-services`. Si usas GitHub Free y quieres usar Pages, necesitarás un repositorio público.
2. Sube `index.html`, `.nojekyll` y `README.md` a la raíz de la rama `main`.
3. En Settings → Pages, selecciona Deploy from a branch, rama `main`, carpeta `/(root)`, y guarda.
4. Una vez publicado, la URL prevista es `https://joseconca.github.io/web-jcf-services/`.

**Importante:** GitHub Pages restringe el uso como alojamiento gratuito para negocios en línea o sitios principalmente orientados a facilitar transacciones comerciales. Antes de utilizarlo como web profesional pública, revisa https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits. El sitio se puede alojar sin cambios en otro proveedor de alojamiento estático que admita webs comerciales.

## Dominio propio

Las rutas son independientes del dominio. Si el proveedor y sus condiciones lo permiten, conecta el dominio mediante sus ajustes y los registros DNS correspondientes. Para GitHub Pages: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site.

## Antes de publicar comercialmente

- Confirmar los servicios concretos, zona de trabajo y datos de contacto.
- Confirmar que se dispone de derechos sobre las imágenes de la tarjeta.
- Completar la identificación del titular, aviso legal e información de privacidad que correspondan a la actividad. No se han inventado datos fiscales ni identificativos.
- No incluye cookies de aplicación, analítica, formularios ni servicios externos incrustados. El proveedor de alojamiento puede tratar datos técnicos de conexión.
